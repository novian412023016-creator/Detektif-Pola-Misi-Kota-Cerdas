# Detektif-Pola-Misi-Kota-Cerdas
Genre: Mencari Pola gambar yang sesuai PC Engine: Greenfoot Target Player: anak SD kelas 1-3
Game ini memiliki beberapa level dari easy, medium hingga hard dengan mekanik yang berbeda, sehingga pemain dapat bermain secara bertahap
Pemain diharapkan dapat belajar juga dalam menggunakan keyboard dan mouse

Jenis soal Easy: mengenali pola sederhana
Mekanisme level Easy:
Keyboard: berjalan menuju papan soal.
Mouse: klik jawaban.
Nyawa: 3.
Waktu: tidak dibatasi.

Jenis soal Medium: mengenali pola dengan distraksi.
Mekanisme level Medium:
Ada benda bergerak di layar.
Pemain harus tetap fokus.
Waktu 20 detik tiap soal.
Skor lebih tinggi daripada Easy.

Jenis soal Hard: mengingat urutan sekaligus fokus.
Mekanisme level Hard:
Urutan 6–8 objek.
Objek hanya tampil beberapa detik.
Ada karakter musuh yang berjalan sebagai distraksi visual.
Nilai maksimal paling tinggi.
