# Detektif-Pola-Misi-Kota-Cerdas
Genre: Mencari Pola gambar yang sesuai PC Engine: Greenfoot Target Player: anak SD kelas 1-3
Game ini memiliki beberapa level dari easy, medium hingga hard dengan mekanik yang berbeda, sehingga pemain dapat bermain secara bertahap
Pemain diharapkan dapat belajar juga dalam menggunakan keyboard dan mouse
